# Imagery

The glass set: one image per function, 16:9, WebP 1600px. Light images (sources, mapping-light, duplicates, catalogue, enrich-light, translate-light, localise) go in light sections; dark images (mess-to-order, mapping, catalogue-dark, enrich, auditor, translate, channels) in dark sections, never dimmed. Always shown whole: no crop, no fade, no scrim. Words only in a listed empty zone; see the passport in **Imagery**. Always `alt=""`.
