# Icons

Lucide, the exact version the prototype ships (`lucide-react` 0.575). These files are the shell's own set, drawn in `#717178` (= `muted-foreground`, Light) because an image cannot inherit colour. In code, import from `lucide-react`; icons take `currentColor`.

- 2px stroke, round caps and joins, 24 viewBox.
- 16px in buttons and dialogs, 14px in nav, toolbars and inline notes.
- `sparkles` is the AI / Enrich mark. `triangle-alert` is the amber note and banner icon.
- `house` Home · `download` Sources · `boxes` Catalogue · `share-2` Output channels · `settings` Settings.
- Never emoji, anywhere in the UI.
